# NAVOI — A city in a different time

A responsive, English-language digital presentation about Navoi, Uzbekistan. Designed as an editorial field guide rather than a generic slide template.

## What's inside

- `index.html` — page content, sections, and source links
- `styles.css` — responsive visual design and presentation-mode layouts
- `script.js` — reading progress, mobile menu, reveal effects, and keyboard-controlled presentation mode

## Run locally

No build tools, packages, or framework are required. Open `index.html` in a browser, or use the VS Code **Live Server** extension for a local preview.

## Presentation mode

Click **Present** in the top-right corner. Use the left and right arrow keys (or the controls at the bottom) to move between sections. Press **Esc** to exit. The page also works as a normal scrolling website when presentation mode is off.

## Publish with GitHub Pages

1. Create a new GitHub repository.
2. Upload `index.html`, `styles.css`, `script.js`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select the `main` branch and `/ (root)`, then save.
5. Wait for GitHub Pages to publish the site and open the URL shown in that section.

## Image note

The site uses image URLs from external tourism and travel publishers so the project remains lightweight. Internet access is needed for those photos. The photography remains the property of its original publishers; the site links back to source pages where possible. Before using the project for public/commercial use, review each publisher's image-usage terms. You can replace any image URL in `index.html` or `styles.css` with your own licensed photo.

## Research notes

Facts and historical dates are paraphrased from the sources linked in the site, including Uzbekistan Travel, Navoi Mining and Metallurgical Company, Explore Uzbekistan, Visit Uzbekistan, the International Paralympic Committee, and the Queen Elisabeth Music Chapel. Historical sites described here are in the wider Navoi region unless a section specifically says they are in the city.
